Everyday Unraveled Metrics

A local, read-only dashboard for the project owner to compare the performance of their own videos across YouTube, Facebook, Instagram and TikTok.

The dashboard runs on the owner's computer. This website provides information about the integration; it does not host the dashboard, offer public account connections, or display private account data.

What is being tested

Video views, likes, comment counts and shares where the platforms permit access. Published comments may be displayed locally when the owner authorizes the required access. Some connections and permissions remain pending. There is no automatic posting, messaging or comment moderation in the dashboard.

TikTok integration is in development for testing with the owner's account. It has not been approved for public use.
